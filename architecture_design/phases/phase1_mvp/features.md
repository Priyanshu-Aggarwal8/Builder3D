# Phase 1 Features
- **Project Management:** Create/read/update projects. Store user inputs (plot, rooms, etc.).  
- **Design Generation:** Generate a simple 2D floor plan automatically (divide area by rooms evenly, basic shape). Return layout JSON + simple SVG/PNG.  
- **Calculation:** Compute areas for each room. Provide summary of material quantities (approx.) in response.  
- **BIM Output:** Export a basic BIM data model (e.g. IFC or JSON schema) for the layout.  
- **User Authentication:** Register/login (JWT). Associate projects with users.  
- **UI:** Angular forms to input project and display result (no heavy styling required).
