# Phase 1 Acceptance Criteria
- **Functionality:** For valid input, the system returns a plausible layout and persists data.  
- **Correctness:** Room areas sum to plot size (within tolerance). Data in DB matches UI.  
- **Resilience:** 400-level errors on invalid input; 5xx on failure (no silent crashes).  
- **Usability:** Basic UI works in modern browsers.
